## Warnings

1. **`scripts/check-gate-buckets.sh:297` is the repo's only BRE `\|`.** `grep -cv '^[[:space:]]*\(#\|$\)'` uses GNU-BRE alternation. Every other `\|` in `scripts/`, `tools/` and `plugins/` (`check-fail-open-shapes.sh:82,84`, `prose-blockers.sh:152,246`, `check-lean-chain.sh:380`) is an escaped literal pipe inside an ERE or awk program — there is no precedent proving BSD grep handles this form. `selftests-bash32` (`.github/workflows/ci.yml:382`) runs the full suite on `macos-latest`, and `(g1c)` asserts the row count *exactly*. If BSD grep reads `\|` literally, the count inflates and that lane goes red. `grep -Ecv '^[[:space:]]*(#|$)'` is portable and equivalent.
